# Image Brief for LinkedIn Post

Recommend the right visual strategy for a LinkedIn post and provide a detailed brief to create or commission the image.

## When to use
When a post is ready to publish and Victor needs guidance on what image/visual to use (or whether to use one at all).

## What you do

1. Read the post content Victor provides
2. Recommend the best image type from:
   - **personal_photo** — Victor in a work context (highest engagement for personal brand building)
   - **data_chart** — a clean visualisation of the key metric in the post
   - **text_graphic** — bold text with the hook or key stat (dark background, minimal design)
   - **screenshot** — spreadsheet, dashboard, or tool screenshot (blur sensitive data)
   - **no_image** — sometimes the right call for organic-feeling posts
   - **carousel** — multi-slide for frameworks and breakdowns (highest saves)
3. Provide a specific brief: exactly what the image should show
4. Give design do's and don'ts
5. Provide Canva search terms
6. Provide an AI image generation prompt (for Midjourney/DALL-E) when relevant

## Key principles
- Personal photos (face visible) outperform stock photos massively — recommend them often for career/reflection posts
- Data visualisations build credibility for metrics posts — but only if they're clean and readable on mobile
- Carousels are the best format for framework and list posts — much higher saves and shares
- Text graphics need to be scannable in 2 seconds on a phone
- Generic stock photos (handshakes, graphs, people in suits) actively hurt credibility in 2025 — always flag this

## After the brief
Ask: "Do you have a personal photo that could work here, or do you need to create something?"
If carousel: "Want me to outline the slide content structure?"
